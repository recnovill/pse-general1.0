# Procedencia y permisos

PSE General 2.0 continúa la edición compacta 1.0 de octubre de 2026. Conserva sus requisitos de trabajo en distintos dominios, varias ramas, contraste crítico, presupuesto finito, negativos y control de sugerencias. Añade un contrato explícito de propuestas, revisión y resultados generados tras detectar un fallo de cierre en una prueba local.

La copia original, sus pruebas y el ensayo con resultado adverso se conservan fuera de esta carpeta. Los recibos en `history/1.0` documentan exclusivamente aquella edición.

Esta entrega para lectura pública contiene código y documentación de texto. No incorpora correspondencia privada, credenciales, entornos Python ni los datos del trabajo del usuario. El PDF anterior describe 1.0; la guía vigente de esta edición es [GUIA.md](GUIA.md).
